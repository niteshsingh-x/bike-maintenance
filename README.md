# 🏍️ Pro Bike Care - Bike Maintenance Website

A modern, responsive web application designed to help bike owners manage their maintenance schedules, estimate service costs, and book appointments. Built with HTML, CSS, and JavaScript.

![Project Status](https://img.shields.io/badge/Status-Active-green)
![License](https://img.shields.io/badge/License-MIT-blue)

## 🚀 Features

- **🏠 Hero Section**: Engaging landing page with call-to-action.
- **🛠️ Services Overview**: Detailed cards for Oil Change, Chain Service, Brake Check, and more.
- **💰 Cost Calculator**: Interactive JavaScript tool to estimate maintenance costs in real-time.
- **📝 Booking Form**: Simple form to submit service requests.
- **📱 Responsive Design**: Works seamlessly on desktop, tablet, and mobile.
- **🎨 Modern UI**: Dark theme with neon accents (similar to SAMS project style).
